Privacidade

Como o devguia.dev trata dados no navegador

Este site foi construído para ser simples e honesto. Hoje ele não usa analytics nem cookies de rastreamento. A persistência existente serve apenas para guardar progresso, preferências de interface e resultado do diagnóstico no seu próprio navegador.

1. O que é armazenado

O devguia.dev não usa backend e não coleta dados pessoais para um servidor próprio. O que existe hoje é armazenamento local no navegador para recursos da interface, como progresso do quiz, checklist do roadmap, preferências de filtro e resultado do diagnóstico.

2. Finalidade do armazenamento local

Esses dados existem para que você consiga retomar o diagnóstico, manter itens marcados no roadmap, preservar filtros e continuar usando o site sem perder contexto entre sessões no mesmo dispositivo.

3. Compartilhamento

O projeto não vende, aluga nem compartilha dados pessoais com terceiros. Como o site é estático e sem backend, não existe base própria de usuários nem envio rotineiro desses dados para processamento externo.

4. Como limpar ou bloquear

Você pode remover esses dados a qualquer momento limpando o armazenamento do navegador para este site. Também pode usar navegação privada, limpar `localStorage` manualmente via ferramentas do navegador ou bloquear armazenamento local com configurações específicas do seu browser.

5. Seus direitos

Nos termos do Art. 18 da LGPD, você tem direito de saber quais dados são tratados e para qual finalidade. Como este projeto não mantém cadastro pessoal nem base identificável própria, o tratamento atual é limitado ao armazenamento local necessário para funcionamento da interface.
