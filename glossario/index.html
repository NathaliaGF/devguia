API

Um contrato de comunicação entre sistemas. Em vez de o front-end acessar banco diretamente, ele chama uma API que valida regras, monta resposta e protege dados.

Front-end

A camada que o usuário vê e com a qual interage. Inclui interface, acessibilidade, estados de carregamento, performance percebida e integração com APIs.

Back-end

A parte do sistema que executa regras, autentica usuários, conversa com banco de dados e expõe endpoints para outras camadas.

Deploy

O processo de colocar uma aplicação em produção. Não é só subir arquivo; envolve build, ambiente, variáveis, monitoramento e rollback quando algo quebra.

SQL

Linguagem usada para consultar e transformar dados em bancos relacionais. Saber o básico evita dependência cega de ORM e ajuda muito em análise e backend.
